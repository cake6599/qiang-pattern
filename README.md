# 羌族纹样文化展示网站

> 科研兴趣小组创意项目
> ——传统羌族纹样的数字化展示与声音交互探索

## 一、项目简介

“羌族纹样文化展示网站”是科研兴趣小组围绕**羌族传统纹样数字化表达**开展的一项创意实践。

项目以网页为载体，将羌族传统纹样进行分类展示，并尝试将纹样的视觉特征与声音进行关联，通过 **Web Audio API + Canvas** 构建具有互动性的数字展示形式。

项目尝试探索：

**纹样 → 分类 → 声音生成 → 视觉反馈 → 交互体验**

让传统文化内容以更加直观、具有参与感的方式呈现。

---

## 二、项目创意

传统民族纹样通常以图片、书籍或展览等形式进行传播，用户更多处于“观看”的状态。

本项目尝试增加“听”和“互动”的维度。

根据不同纹样的视觉特征和文化类别，为其设计不同的声音表现：

| 纹样类型 | 声音表现 |
| ---- | ---- |
| 羊角纹  | 低频浑厚 |
| 火纹   | 高频明亮 |
| 云纹   | 空灵飘逸 |
| 几何纹  | 短促清脆 |
| 植物纹  | 柔和起伏 |

用户点击不同纹样后，网页实时生成对应的声音，同时配合 Canvas 动态视觉效果，使纹样从静态图像转变为具有声音和动态反馈的交互对象。

## 三、主要功能

### 1. 羌族纹样展示

对纹样进行分类展示，包括：

* 植物纹
* 动物纹
* 几何纹
* 其他具有代表性的纹样类型

通过卡片形式展示纹样图片、名称及相关介绍。

### 2. 纹样详情

进入具体纹样后，可以查看：

* 纹样图片
* 纹样名称
* 纹样类别
* 纹样描述
* 文化含义
* 相关文字介绍

### 3. 纹样声音生成

项目使用浏览器原生 **Web Audio API** 实现声音合成。

不同类别的纹样对应不同的声音参数，通过振荡器、频率、音量以及 Attack / Decay 包络等参数控制声音效果。

### 4. 交互式声音切换

点击新的纹样时：

* 停止当前纹样声音
* 切换至新的声音效果
* 更新当前播放状态
* 同步更新页面视觉反馈

### 5. Canvas 动态视觉反馈

通过 Canvas 对声音数据进行可视化处理，使声音变化与页面中的动态波形产生对应关系。

### 6. 移动端适配

针对不同屏幕尺寸对页面布局和交互区域进行适配，并针对移动设备上的 Web Audio API 使用场景进行处理。
